# Calculus 1 — Study Hub

An interactive, single-page study website for **Mathematics 1: Calculus**, built from the course
materials (weekly schedule, lecture notes, tutorials, and past midterm & final exams 2023–2026).

🔗 **Live site:** _enable GitHub Pages (see below), then this becomes_ `https://<your-username>.github.io/calculus-1-study-hub/`

## What's inside

Two hubs you switch between with the tab bar:

### 📘 Midterm Hub (Weeks 1–3)
- **Step-by-step concepts** — plain-English intuition → formal definition → worked example, for every core topic (inequalities & absolute value, functions & domains, inverses, exp/log/trig, sequences, induction, limits & ε–δ, limits at infinity, continuity/IVT, derivatives, and all differentiation rules).
- **High-probability exam topics** — ranked by how often they recur across past midterms.
- **Targeted practice** — problems modeled on real midterms, with expandable step-by-step solutions.
- **"Must-Remember" cheat sheet** — formulas, key limits, theorems, and proof recipes.

### 📗 Final Exam Hub (comprehensive)
- All midterm material **plus** applications of derivatives (max/min, MVT & Rolle, curve shape, l'Hôpital, curve sketching) and the full integration toolkit (antiderivatives, Riemann sums, the Fundamental Theorem, substitution, integration by parts, partial fractions, areas, average value, improper integrals).
- Priority topics, practice problems at final-exam difficulty, and a complete master cheat sheet.

## Features
- Tabbed navigation, collapsible self-test accordions, and math rendered with **MathJax**.
- Clean, responsive, light/dark-theme-aware design.
- Fully self-contained — one `index.html`, no build step.

## Run locally
Just open `index.html` in any browser. (An internet connection is needed the first time so MathJax can load from its CDN.)

## Enable the live website (GitHub Pages)
1. Push this repository to GitHub.
2. Go to **Settings → Pages**.
3. Under **Build and deployment → Source**, choose **Deploy from a branch**.
4. Select branch **`main`** and folder **`/ (root)`**, then **Save**.
5. Wait ~1 minute; your site goes live at `https://<your-username>.github.io/calculus-1-study-hub/`.
